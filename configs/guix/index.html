Guix config

GNU Guix is (1) a transactional package manager and (2) a GNU/Linux distribution.

My personal selling points were declarative package configuration and transactional upgrades.

I’ve since switched to Arch Linux but decided to keep this file as a reference. I’ve even spent ~30 hours writing a blog post detailing why but deleted it.
